# Nossa estrutura — CRETA

Nossa estrutura conta com:

- Dormitórios;
- Banheiros;
- Cozinha;
- Amplo refeitório;
- Espaço aberto;
- Capacidade de até cinquenta residentes.

Além de:

- Lago para patos;
- Local adequado para animais;
- Cavalos;
- Galinhas;
- Porcos.

Tudo em uma fazenda que oferece calor humano e vivências potencialmente transformadoras.
